# RC_Entropy
Regional Co-occurence Entropy implementation in R (Nemri et al)

Partition-based spatial entropy for co-occurrence analysis with application in spatial multi-omics  
Adnane Nemri(1,2), Ovidiu Radulescu(1), Antoine Claessens(1), Thomas D. Otto(1,2)
1. LPHI, CNRS, University of Montpellier, INSERM, Montpellier, France
2. School of Infection & Immunity, University of Glasgow, United Kingdom

Requires the following R libraries to run on the 2 example datasets:
dplyr  
patchwork  
ggplot2  
scatterpie  
tidyr  
RColorBrewer  
ggforce  
scales  
sf  
SpatEntropy  
spatstat  
spAbundance  
Seurat  
clustree
